# Start with the writing

**0.27.0 private-preview guide · candidate 04; three qualification gates remain open.**
The handoff is a Mac app and this guide, with no source build or Terminal setup
required. The [release record](RELEASE-0.27.0.md#candidate-identity-and-acceptance)
identifies the exact archive and its scoped checks. Exact compact content sizes,

## Install the private preview

This delivery targets **Apple Silicon Macs**. New activation writing requires
**macOS 26 or later** and at least **8 GiB of free disk space** before preparation.
The development/qualification host runs macOS 27.0.1; the
release record distinguishes passed local checks from the remaining gates. The broader app retains its macOS 14 deployment
target, but that does not qualify activation on older systems or establish a tested
minimum operating system. Intel Macs, Windows and Linux are outside this delivery.

1. Obtain the named private archive and its matching release receipt from Mike.
   Expand the archive in Finder and move **Reservoir Scope Tauri Preview.app** to
   Applications, or another folder you use for applications.
2. Open the app. Candidate 04 has verified local ad hoc signing,
   without an Apple notarization claim. macOS may require an exception for this exact app.
3. If macOS says the developer cannot be verified or Apple cannot check the app,
   and you trust the supplied copy, first attempt to open it, then go to
   **System Settings → Privacy & Security → Open Anyway**. Confirm **Open** when
   prompted. Apple documents this app-specific route in
   [Safely open apps on your Mac](https://support.apple.com/en-us/102445).
4. If the alert instead says the app is damaged or will damage your computer, or
   the expected control is unavailable, retain the exact message and ask for help
   with that copy. The preview does not require disabling system-wide protections.

The Tauri preview has its own application storage. The older native Reservoir
Scope app is a separate product and can remain installed.

## Read before preparing a model

Open **My reservoir → Activation experiment · optional**, then choose
**Read the included examples**. This works offline; no model or Python download
is needed. Opening the experiment does not start inference.

Read each sequence from its first entry using **Earlier** and **Later**. Reading A
contains six completed journals. Reading B contains two completed journals followed
by the entire unfinished third response, including its repetition. The unfinished
response was not saved as a journal or applied as feedback. These writings came
from an isolated Qwen3 experiment, not the live Beings.

Keep your own first impressions before choosing **Reveal conditions, invitations
and interpretations**. The revealed evidence includes the exact writing invitation,
earlier prose supplied as memory, quiet observations, application boundaries and
attributed readings with alternatives. These are separate historical attempts with
different runtime identities, not a matched three-condition comparison. There is
no recurrent-condition journal sequence in this collection.

**Export this reading collection…** saves a portable copy. **Open a reading
collection…** opens it again without a model. This derivative is for reading:
its text hashes are checked, but it is not the complete numerical evidence and
cannot start or resume an experiment. The source-file hashes identify originals
held separately. Condition concealment is a reading aid; allocation is in the file.

## Prepare this Mac for new writing

Choose **Prepare activation runtime** only when you want to download the pinned
dependencies and Qwen3 model. The app installs its own versioned Python runtime and
assets under its Application Support directory. You do not need a system Python,
Ollama server, developer checkout or access to another running system.

Preparation makes network requests for the frozen Python dependencies and model
assets. It shows the current phase, downloaded bytes where available, and required
storage. Its **8 GiB disk check is separate from memory admission** before model
loading. Preparation verifies files; it does not run inference or write journals.

Leave the app open until **Activation runtime ready**. Each preparation attempt
has a **30-minute deadline**. **Cancel preparation** stops the owned setup work and
retains recognized partial downloads. If interrupted, read its message and use
**Check setup status**; **Resume preparation** appears for a recognized interrupted
installation. Reopening the app never resumes downloads automatically. A deadline,
failed download or low-disk refusal is a retained outcome, not a reason to change
the frozen dependencies or extend an attempt silently.

## Run one bounded condition

1. Once the runtime is ready, choose the condition and inspect the twelve quiet
   observations. **Check activation setup**, then **Create activation experiment**.
   Creation prepares a local record; it does not load the model.
2. Choose **Start activation run** explicitly. Start makes a separate memory check.
   If admission is refused, read the diagnostic and retain the prepared record.
3. Follow the observation timeline and complete writing. The sequence has twelve
   observations, ten controlled numerical steps between observations, and one
   writing opportunity after every second observation: at most six journals.
   Each model request has a three-minute deadline and each journal a 1,024-token
   ceiling. Model work and saving hold numerical time.
4. Use **Stop and retain results** when needed. A failure, cancellation or incomplete
   response holds the attempt. Completed evidence stays available; an incomplete
   response never becomes feedback. Recovery does not resend an ambiguous request.

Whole entries remain readable with **Earlier**, **Later** and **Follow latest**.
The timeline distinguishes receiving an observation, saving writing and applying
feedback. Under the selected journal, **Add a reading note** retains an exact
excerpt, your interpretation, another possible reading and linked source events.
Reading notes never enter the model's context or decide whether writing is saved.

From a settled run, choose **Export this run…** for the complete experimental
evidence. Under **Saved activation runs and paused recovery**, refresh and restore
a saved run, or choose **Import activation run…**. Recovery starts for review and
does not silently run the model. A completed or failed run may have Start disabled;
that preserves its boundary rather than extending it.

Raw run exports retain local runtime paths and diagnostics for provenance. The
included portable reading collection omits those host details. Keep that distinction
when choosing what to share.

The [newcomer task card](NEWCOMER-TASK-CARD.md) gives a short, uncoached first-use
session. Keep the exact app version, what you tried, what you expected, the result,
