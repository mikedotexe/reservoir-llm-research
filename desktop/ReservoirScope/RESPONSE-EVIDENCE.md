# Response evidence and preparation history

Preview 0.6 adds two deliberately separate response readers to the Observatory.
These are retained offline evidence. Opening either reader starts no experiment,
model, file watcher, or connection to a Being.

## Native immediate action boundaries

`native-action-response.json` contains an isolated native rehearsal, not a running
Being capture. The supplied observation clock is not measured wall time. Applied
and no-op receipts provide the ordinary result of one successful step, the result
after its action, and the exact Float32 difference. The ordinary result is not a
separate counterfactual trajectory. Admission, completion, failures and headroom
rejections remain inspectable events; they do not become recovery trajectories.

The reader validates bounded dimensions, identities, source hashes, successful-step
order, exact Float32 coordinate subtraction and full-vector displacement summaries.
Wide clocks and step IDs cross IPC as decimal strings. Requested dose, attenuation,
actual L2 displacement, clipping, effective leak and realized noise retain their
separate meanings. Neither measured fill nor a PCA basis is present.

An explicitly chosen external rehearsal can replace the bundled example. Within
an existing source identity, overlapping boundaries are immutable and the accepted
batch cannot move backward. Swift-compatible canonical Unicode equality is used only for
comparison; original strings remain intact. Ambiguous canonically duplicate source-hash
keys are explicitly unsupported by this bounded reader. A rejected or cancelled replacement preserves the last
usable reading. A different session starts a separate reading. No historical path
inside the record is opened. Original-byte export uses the accepted backend snapshot.

## Retained esn-divide simulation

`state-response.json` is a 65-frame paired response under identical recorded forcing
and transition residuals. It is not a native checkpoint replica or a cloned adaptive
controller. Boundary zero already includes the coordinate-zero displacement; the
following 64 boundaries show the retained path. Boundary indices are not seconds.
The simulation has its own coordinate identity, no measured fill, and no Minime PCA
basis. The renderer's preview size has no measurement meaning.

Rust checks the frozen byte identity and native structural/semantic rules, including
all paired differences, L2 distances, peak gain and the eight-boundary return dwell
at ten percent of initial distance. This checks a retained result, not regeneration
of the simulated model. The complete summary is a retrospective inspection result.

## Presentation and lifecycle

State scales remain −1 to +1. The native difference uses one extent for the entire
accepted bundle; simulation differences use the declared ±0.001 displacement scale.
The renderer interpolates original coordinates before applying the fixed display
scale. Color and relief saturate outside that scale; exact coordinate values do not.
No frame normalizes itself to its own maximum.

Single-field inspection and paired-state comparison use the existing coordinate
atlas. Paired surfaces share camera and coordinate selection. The atlas is a drawing
map, not physical anatomy, connectivity, or full phase-space reconstruction. At most
two response surfaces are mounted for comparison. Event-driven rendering, bounded
raster sizes and visibility suspension remain in effect. Hardware GPU efficiency
still requires measurements on each supported platform.

Backend handles retain original bytes; selected frames/events carry operation and
handle identities. Navigation and hidden-window behavior pause recorded playback;
late requests cannot replace a newer selection. This playback behavior is separate
from the future sustained experiment scheduler, which must keep running while the
application is open or minimized.

## Preparation history

The Library and Observatory expose the original preparation report, the separately
retained protocol correction, and the September 16 retry. The original was
unavailable; the correction froze a protocol without executing it; the retry retained
a failed partial experiment whose historical record verification passed. Those are
three different facts. Report inspection does not recheck model availability or run
a new numerical verification. Opening one of the four retained preparation examples
uses the experiment reader and its current verifier.

Each report export preserves its exact bundled bytes. Source filenames, endpoints,
commands and historical verification claims are inert text. A report's expected hash
is checked before opening Save. The metadata reader is bounded to 128 KiB and does
not interpret missing counts as zero or missing verification as success. Refresh and
selection errors remain visible without replacing accepted report content.

## Qualification

Core, desktop-boundary and frontend lifecycle tests cover the contracts above. The
independent response oracle compiles the unchanged Swift readers alongside a small
output adapter and compares every retained numeric value with Rust. Negative tests
exercise altered differences, dimensions, clocks, source identities and replacement
rules. Candidate receipts, actual packaged UI observations, package hashes and
unexecuted platform/performance gates are retained in `validation/`.
