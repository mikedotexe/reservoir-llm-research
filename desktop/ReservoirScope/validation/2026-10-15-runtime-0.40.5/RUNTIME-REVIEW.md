## Changes that matter, without widening the audit

The only change in `server/routes.go` adds cloud passthrough middleware to `/v1/systemone`; the `/api/chat` registration and complete `ChatHandler` and `Serve` functions are unchanged. Cloud proxy changes stop HTML-escaping JSON and revise authentication errors. OpenAI `/v1/responses` compatibility gains custom-tool-call parsing and authentication-error fields. Renderer selection adds a Nemotron variant. These are not the frozen local Gemma `/api/chat` request path; they are retained and reviewed rather than described as absent. [Exact route change](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/server/routes.go#L2395), [proxy](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/server/cloud_proxy.go#L164), [OpenAI compatibility](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/openai/responses.go#L372).

The **llama.cpp pin changes from `b11521` to `b11669`**, and the MLX pin also changes; MLX-C remains identical. The full upstream inference-library delta was not audited. This is a material reason not to claim identical text, tokens, timing, memory use, completeness or context behaviour. Prior 0.40.4 outcomes do not qualify 0.40.5 output. [llama.cpp pin](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/LLAMA_CPP_VERSION#L1), [MLX pin](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/MLX_VERSION#L1).

The main executable/plist do not identify every bundled runner/dylib or prove source-to-binary correspondence. Runner lookup searches local package/build locations and is unchanged. A later run must record the actual owned runner/runtime evidence and reject unexpected identities under its frozen plan. No updater, GUI launcher, CLI client, remote model, alternative runtime or default-service discovery is covered. [Lookup](https://github.com/ollama/ollama/blob/d919272e53593d1d55d40e1180eaa06dfbede3ac/llm/llama_binary.go#L39).
