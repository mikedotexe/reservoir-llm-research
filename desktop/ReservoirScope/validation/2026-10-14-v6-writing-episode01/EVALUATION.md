## What was supplied, retained and asserted

V6 supplies current step/time and previous observation step, recurrent RMS and
separate sensory fill with current/prior values and signed changes, and
state-coordinate L2 distance since the previous observation. Missing prior values
remain unavailable. Full state vectors, sensory spectra and the human eight-row
reference are retained, but their presence in the export does not mean the model
was shown them. Use the exact request prompt to identify exposure.

The new context states: “Writing is the only action available here. Describing a
control change or experiment does not execute it, and no new readout arrives while
this entry is written.” This is a constraint of the app's action path, not a
required subject or response format. Accepted writing still travels through the
existing numerical-feedback path and separately through full-text carried memory.
An automatic numerical consequence is not evidence that a prose-described control
command was executed.

Preserve provider input evidence as absent, exact unsigned integer reported, or
unusable with its retained reason. Summary counts stay exact decimal strings;
zero is a reported value and absence is unknown. Requested context, provider
input count, output count and UTF-8 length are different quantities. Optional
metadata does not add a completion/save gate. Provider/runner evidence does not
prove tokenizer fit, full-context processing, attention, comprehension or truth.
Keep any independent runner logs and their join limitations separate.

## Reading and reporting

Read every full received response in order and against its exact supplied context,
following the [rubric](RUBRIC.md). Preserve faithful readable prose, twelve-slot
coverage, per-entry attention notes and source-linked findings. Read incidental
or unmatched factual claims manually; an extractor provides candidates, not an
exhaustive denominator or automatic scientific/creative verdict.

Report mechanical delivery, continuity, subject/form and voluntary factual/action
claims separately. Distinguish a hypothetical experiment or metaphor from a claim
to have performed an operation and witnessed a new result. No metric count,
heading, persona, emotional performance or stylistic score determines success or
save eligibility. If counts of claims are useful, state the annotation rules,
unit, ambiguous cases and denominator in auditable material rather than inventing
an overall accuracy percentage.

The known [v5 twelve-entry episode](../2026-10-13-v5-writing-episode01/README.md)
motivates the scope clarification; it is not a blinded or unseen control. Even
with matched initial settings, different returned text changes later feedback and
state. One dependent v6 sequence cannot identify a causal prompt effect or general
writing quality. A later recovered export receives its own replay and exact file
comparison; it must not rewrite the original response outcome. Prior receipts and
this prospective plan remain unchanged after output.
