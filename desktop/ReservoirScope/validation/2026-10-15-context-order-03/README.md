## Decision and next question

Do **not** promote the block swap or create v9 from this result. Preserve the open subject/form, current full prior-text memory and existing v8 order. The comparison jointly moves two blocks in six dependent snapshots from one known episode, with one response per condition, on one local model/runtime. It does not isolate attention, comprehension, recency, or a general mechanism of repetition, and it does not measure a continuing feedback loop or the live Beings.

A useful next bounded proposal is to examine the remaining time/direction misunderstandings separately from imaginative language, using examples that include both the correct scalar values and their mistaken interpretation. A later continuity or context-selection experiment needs its own prospective design and resource window. No further run, cleanup or prompt change is automatic.
