# Private preview qualification boundary

Frozen before the new runtime is loaded for inference. Source and package repairs
may receive affected software checks; each real-model attempt retains its own
identity and outcome. No live service is changed or unloaded.

1. Verify the pinned bootstrap, all 34 wheel identities, and nine expected model
   files. Test explicit setup, cancellation, recovery and the exact derivative
   reading collection before compiling the candidate.
2. Build one-job macOS release packages. Package identity is separate from source
   qualification; later changes require an explicit new candidate identity.
3. In a fresh owned app-data directory, open the actual packaged app with no
   developer tools on PATH. Read both included sequences offline, then explicitly
   prepare its standalone runtime. Retain installation progress and hashes.
4. Run the existing fourteen fixed real-model qualification checks using that
   standalone interpreter, after the existing normal-pressure/25%-free admission.
   Preserve a refusal or failure; do not change thresholds or probe tolerances.
5. After mechanical qualification, run the default decaying-trace condition
   through the packaged UI with its original twelve observations, seed, 1,024-token
   ceiling and 180-second request deadline. This is a bounded workflow check,
   not a new condition comparison. Stop after observing the first saved and
   applied journal. Preserve any additional operation already dispatched before
   Stop. A failed request ends this attempt; no automatic writing retry or limit
   extension. Export, quit, reopen and restore paused; verify the retained files.
6. Use synthetic fixtures for interrupted/incomplete/failed outcomes and navigation
   under arrivals. Check actual 900×700 and 720×600 content dimensions, keyboard
   reading, 125%/200% zoom, the relocated app, and archive opening under macOS's
   normal quarantine behavior. A check not observed remains unqualified.

All real writing produced during workflow qualification remains separate from the
bundled historical examples. No editorial judgment controls saving or feedback.
Newcomer acceptance requires an actual person; agent walkthroughs cannot fill it.
There is no public publication, new comparison, or live-system rollout in this
tranche.
