# User-directed change before any v2 output

The constrained `reservoir-journal-v2` rehearsal and its evaluation protocol were superseded before any v2 model requests or outputs. The user's objective is an ongoing space for self-directed writing, not a prescribed measurement report. V2's mandatory `Step N.` opening, RMS/fill recitation and requested word range are therefore not the current product or quality target.

The earlier [protocol](PROTOCOL.md), [run plan](run-plan.json), [rubric](RUBRIC.md), [evaluation freeze](evaluation-freeze-01.json), tests and v1 reference reports remain historical. The exact frozen evaluator/test source bytes were copied to [superseded-v2-source](superseded-v2-source/preservation.json) before amendment; their hashes match the old freeze. No prior model text, receipt or runtime record was rewritten. V1 and the unexecuted v2 prompt bytes remain distinguishable in the core version contract.

The replacement is `reservoir-journal-v3`, OpenJournalV3. The [v3 run plan](run-plan-v3.json), [v3 review contract](RUBRIC-V3.md), [design note](OPEN-WRITING-DESIGN.md) and subsequent v3 freeze govern new outputs. The model may choose its topic and form, continue, revise or leave an earlier thread, and use the current readout as context. No heading, number of words, numerical metric or creative form is required by the quality rubric.

Optional literal factual claims can still be checked against the information actually supplied. Metaphor, imagination, questions and self-description are not automatically treated as unsupported scientific assertions. Reviewer judgments do not block saving or feedback and do not trigger rewriting or extra generation. Mechanical response completeness, exact saving and application retain their existing separate contracts.

The newly authorized rehearsal remains four attempts, unchanged numerical/storage/time limits, the same selected model identity and the existing 256-token output limit. That is a resource bound, not a requested prose length. If open writing reaches it, preserve the incomplete outcome; do not retry or silently extend the budget. No new v3 result is claimed by this supersession record.
