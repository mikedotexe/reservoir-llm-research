# Open-writing evaluator preparation

The current prospective contract is [PROTOCOL-V3](PROTOCOL-V3.md), [run-plan-v3](run-plan-v3.json) and [RUBRIC-V3](RUBRIC-V3.md). The constrained v2 rehearsal was superseded before any model output; [SUPERSESSION-01](SUPERSESSION-01.md) preserves that boundary and the original frozen sources. No v3 result is claimed here.

The quality harness accepts v3 with no mandatory heading, metric, word count, topic or form. Its extraction is a deliberately partial reading aid: literalness, time/subject and creative context must be established before calling a number a factual error. It never awards a global quality pass or controls saving/feedback. The v3 tests retain the prior numerical/precision/bounds tests and add free-form, no-claim, creative-language and protocol-version cases.

The [copied integrity checker](check_real_model_export.py) requires the expected retained prompt version. It keeps legacy raw-memory behavior for v1, and exactly decodes one JSON-string memory line for v2/v3, including multiline, Unicode, quote and backslash text. Duplicate/missing/malformed lines, altered text, mismatched memory object/path/application/hash and version changes fail. Synthetic structural fixtures test those joins without pretending to be numerically valid records; actual use still requires the pinned whole-chain verifier first.

A peer review found that incomplete replies can be retained as `languageReceived` and a blocked phase without a saved journal. The new checker therefore reports bounded received-response evidence separately, including real stop/completeness, exact original byte count/hash, explicit truncation, attempt association and nullable saved journal identity. The quality report carries that mechanical outcome and final phase while only saved journals enter the journal rubric. A zero-journal cutoff remains an explicit outcome.

Executed synthetic tests, command output, closed UTC intervals and source hashes are retained in `quality-v3-tests-02.{json,log}` and `memory-checker-tests-02.{json,log}`. The first v3 test run remains historical; the second covers the peer-review outcome fixes. `evaluation-freeze-v3-01.json` binds the final prospective files and immutable prior evidence. Runtime, UI, native verifier and model calls were not executed by these tests.

Actual run instructions: invoke this directory's checker with absolute `--bundle`, `--executable`, `--expected-executable-sha256`, `--expected-model`, `--expected-endpoint`, `--expected-prompt-version reservoir-journal-v3` and a fresh `--output-directory`. Then invoke `scripts/journal_quality.py` with its bound `--material`, `--integrity-receipt`, `--protocol` pointing to `run-plan-v3.json`, `--prompt-version reservoir-journal-v3` and a new `--output`. Review all prose and unsaved outcomes separately; these scripts never authorize extra requests.
