# 0.25.0 — Put the journal first

The journal now leads My reservoir: selected prose and Earlier/Later controls
precede the history list, with the current sensory fill and recurrent state beside
it at wide sizes and below it at smaller effective widths. Setup explains the
included save-and-feedback loop and how to select an installed local Ollama model.
The [first-use walkthrough](../../GETTING-STARTED.md) takes a collaborator from
build prerequisites to their first saved entry.

This is an interface/documentation tranche. Production `reservoir-journal-v8`,
its open writing invitation, numerical mechanisms, model transport, persistence
and feedback eligibility are unchanged. No real model was contacted. Minime and
Astrid and their services were untouched.

## What 68% means

The personal reservoir has a separate reduced sensory covariance field. Its
active-mode fill is a smoothed percentage, not a rate, occupied-node percentage or
memory usage. The existing retention controller uses a 68% target and a 64–72%
deadband. Retained integral state may still influence retention inside that band.
These are configured controller settings, not demonstrated evidence of a special
writing or emergent state near 67–70%, nor a guarantee that the target is reached.
The current fill is visible in the session status; the controller reference is in
optional numerical details when regulation is enabled.

Historical Minime recordings use their own mechanisms and policy references. They
must not be equated with this reduced personal field. Source references are
[ReducedFill/RetentionController](../../crates/reservoir-core/src/math.rs) and the
[sustained numerical step](../../crates/reservoir-core/src/sustained.rs).
