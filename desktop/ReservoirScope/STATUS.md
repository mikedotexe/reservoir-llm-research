# Reservoir Scope: current status and next work

**October 15, 2026 · Product 0.20.0 · Open-writing prompt v8**

The personal reservoir loop works: a bounded run can generate writing, save and read
it back, apply its encoded signal at the next numerical step, and carry the exact
latest eligible journal into later context. It has a readable journal history and
explicit paused recovery. The wider cross-platform Observatory and everyday-use
qualification are still incomplete.

  both strict Clippy checks; two opt-in desktop tests remain ignored. Fourteen
  historical exports replayed with all 665 original files unchanged. Native
  synthetic save/held-response/export/recovery checks passed. These are scoped
  agent checks, not whole-product or collaborator acceptance.
- **Actual app writing:** the [v8 episode](validation/2026-10-14-v8-writing-episode01/README.md)
  completed twelve saved/applied journals and eleven exact previous-text joins,
  reaching step 361 after 527,132 ms active time. Native export and paused recovery
  preserved all 72 nonmanifest files. These are saved app journals; later standalone
  diagnostic replies did not enter the app or its feedback loop.
- **Reading experience:** Earlier/Later navigation, explicit pinning, closed optional
  evidence and responsive complete prose are implemented. Pending/skipped states
  and errors stay visible. Native checks cover within-page reading and historical
  recovery; cross-page/new-arrival races have frontend tests, not native multi-page
  acceptance.
- **Evidence has limits:** the two complete v8 readings find continuity and repeated
  composition. All 35 selected recurring current-value mentions match, but entries
  11 and 12 reverse interval-distance comparisons. That selected count is not a
  whole-text accuracy score. Neither reading found clear concrete unavailable-control
  execution; this does not establish understanding, experience or causal improvement.

The unchanged v8 prompt explains measurement meanings while leaving topic and form
open. Full retained observations remain inspectable; only the compact selected
readout is supplied in v8 context. Saved text becomes full-text memory only after
actual application. Describing controls in prose does not execute them.
