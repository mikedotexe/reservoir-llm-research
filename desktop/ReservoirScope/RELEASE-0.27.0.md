**October 16, 2026 · implementation in progress; candidate qualification pending.**

read and explore without a source checkout. It is not yet a qualified delivery.

## Changes in this tranche

- In-app preparation installs a private pinned Python runtime, hashed dependencies
  and pinned Qwen3 model. Downloading begins only on **Prepare activation runtime**.
  A 30-minute preparation deadline, cancellation and explicit interrupted-install
  recovery keep setup distinct from Create and Start. The activation route requires
  Apple Silicon, macOS 26 or later and 8 GiB free disk before setup.
- The private package carries an offline reading collection: six completed trace
  journals from the October 15 pilot, two completed unsteered journals from the
  October 16 headroom attempt, and its entire unfinished third response. Conditions,
  exact invitations and attributed interpretations are disclosed deliberately.
  Exact text, prompt and note hashes plus source references travel with the collection.
- A portable reading export is a separate inert format,
  `activation-reading-collection-v1`. It cannot start a worker, resume an experiment
  or supply feedback. Existing complete experimental exports retain their original
  evidence contracts and may include local paths.
- The preview includes install-first guidance and a newcomer acceptance task card.
  The exact package still needs its coordinated checks and actual-app walkthrough;
  human acceptance requires an actual participant.

Downloaded bootstrap archives, model assets and the real reading collection remain
ignored local packaging inputs. The collection is not a new public
data publication. The bundle's content inventory must identify exactly what is
included before a handoff.

## Evidence and limits

The [October 16 headroom account](validation/2026-10-16-activation-headroom/README.md)
records fourteen passing real-model qualification checks for that worker/runtime,
followed by a stopped cohort with two completed unsteered journals. Its third
response reached the frozen 1,024-token ceiling; recurrent and trace conditions
remained unstarted in that cohort. The earlier trace sequence belongs to a different
attempt and runtime identity. Together these examples are useful reading material,
not a completed controlled comparison or evidence of a recurrent advantage.

Existing numerical steps, calibration/capture semantics, intervention norm, writing
invitation and feedback eligibility remain governed by the
[activation contract](../../shared/reservoir-scope/activation-experiment.md).
The visible single-condition Start retains twelve observations, six scheduled
writing opportunities, a three-minute request deadline and a 1,024-token output
ceiling. Setup's 30-minute allowance is not an extension of those inference bounds.
The headless serial cohort remains a separately bounded path.

The current development/qualification host is Apple Silicon running macOS 27.0.1.
That host identity does not establish a passed 0.27.0 package walkthrough, macOS 26
minimum-version testing, a second-Mac installation, broad accessibility acceptance,
endurance, or Windows/Linux behavior. The native 0.15.0 build 21 candidate and its
unfinished human-review scope remain separate. Live Being systems are untouched.
