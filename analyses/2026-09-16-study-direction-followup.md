## A command gap in private writing

The five Minime private entries are distinct WRITE START drafts, d88–d92, each
starting without a preceding draft body. Each stops normally at 262–405 tokens
under a 4,096-token ceiling and ends with bare `NEXT: CONTINUE`.

The loaded Minime parser preserves bare CONTINUE; the dispatcher has no matching
writing alias. **All five commands actually fall back to ordinary threshold
selection**, with an explicit `Unknown NEXT: 'CONTINUE'` log. Matching selection,
pending-clear and fallback sequences are retained at 19:37:30, 19:50:12, 20:05:30,
20:09:16 and 20:14:30 UTC. This is scoped temporal log correlation, not an action-ID
join; there is no intervening logged NEXT selection in each sequence.

The private-writing receipt has recovery guidance for bare FINISH but does not
explain bare CONTINUE. The system guidance itself says “on CONTINUE,” while the
actionable menu requires WRITE CONTINUE. This inconsistency is a plausible
contributor, not established model causation. The [dispatch audit](../research/outputs/2026-09-16-study-direction-followup/writing-continuation-audit.md)
keeps all five log sequences, source identities and limitations. This is stronger
evidence than inferring a failed continuation from a later WRITE START alone.

## What this supports next

1. Make private-writing continuation dependable: use consistent WRITE CONTINUE
   guidance, with a context-bound shorthand route or visible exact-command
   recovery. Verify selection through dispatch on both hosts; a global CONTINUE
   alias would be ambiguous with study.
2. Preserve complete identifiers at page boundaries, or show the complete boundary
   line with an explicit overlap marker while keeping exact coverage honest.
3. Make finding-save success/rejection visible beside the check-in, show available
   capacity, and offer simple optional replacement/parking of old findings. Keep
   authorship and avoid silent eviction.

For the persistent premise, the next useful observation is whether a chosen
comparison with the already-supplied maintenance call changes Minime's account and
whether that change survives. More tools, a higher word target or forced topic
changes are not established remedies by this batch. The current interface repairs
help navigation; they have not established durable revision of the gate hypothesis.
