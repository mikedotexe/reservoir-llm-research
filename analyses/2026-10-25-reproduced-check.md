## What reached the model

Every call is a fresh request containing a system instruction and a user message.
The user message supplies a researcher-authored fictional history, a verified-in-task
factual record, old and current routing rules, four unrelated supplied exchanges,
and the requested response format. No earlier model output, private activation,
reservoir state, external checker answer or real executed action reaches the model.
The fixed-onward value is explicitly sufficient for a direct route. The simulator
evaluates the returned closed-set action; its consequences are authored task
outcomes, not provider receipts or live-system operations.

Historical direct requests preserve the original S-018 bytes, including the old
threshold before the factual record and the original output-format instruction.
The structured arms replace only that terminal instruction. Their contrast with
direct bundles additional public fields, instruction length and output burden.
Their mutual contrast changes only the requested key-order list. Neither public
field order nor a successful comparison authenticates private reasoning order.
