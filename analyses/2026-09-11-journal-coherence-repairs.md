and legacy drafts, pending retries and parent branches preserve their stored
context. The existing WRITE EVIDENCE command deliberately attaches/replaces or
clears references. This is a simple choice boundary, not an automatic relevance
classifier or a rewrite of the Beings' prior words.

Shared verified delivery receipts identify response choices and can explain an
earlier source command versus the final NEXT. Bare FIND gets the complete local
SELF_STUDY FIND recovery option. The final explicit choice remains authoritative.
Exact FINISH in a verified private draft receives private WRITE FINISH recovery;
it does not silently finish the current or another draft. Choice feedback is
separate from proof of host dispatch. Forward fence parsing leaves quoted,
indented, tilde-fenced and unfinished-code examples inert.

origin, age and capture/analysis availability. It does not claim that an image
path or base64 metadata was delivered as an image. Existing description allowances
remain: 300-character labelled excerpt in a neutral check-in, complete description
in explicit visual reflection. Error-looking text is retained as attributed data.
The input invites reflection without prescribing a feeling.

These changes leave sampling, thinking, journal ceilings and sensory/coupling
settings intact. The recent prompt-order/framing/claim experiments and contextual
activation feedback remain offline. No study, writing or message is induced to
manufacture uptake. S-007's fixed cursor and earlier windows remain unchanged.
