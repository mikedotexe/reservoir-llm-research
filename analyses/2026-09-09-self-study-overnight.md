## Actionable barriers and today's decisions

1. **Maps invite returning to a few entry files.** `MAP kernel` displays four
   curated entries, with delivery labels but no adjacent-directory commands.
   The implementation adds directory navigation to every component map.
2. **Small path errors become large detours.** Retained requests use
   `astrid_kernel` or `astrid_capsule` in paths whose real directories have
   hyphens. Recovery now suggests matching exact catalog spelling without
   opening a substitute or moving the bookmark.
3. **An explicit read choice can disappear for lack of a prefix.** Six Astrid
   responses end in a bare SELF_STUDY command; the old parser records no NEXT.
   The first two are EOF cases asking to open dialogue_runtime.rs. Both adapters
   now recognize an unfenced, unquoted final source-study command; other Actions
   still require their existing syntax. Original writing is retained.
4. **READ_MORE is being requested without new verified reading.** Twenty-four
   Astrid READ_MORE Actions are marked handled, but this capture contains no
   newly accepted saved-reading delivery. The last request discusses continuing
   orchestration.rs. Ordinary prompts now distinguish source continuation from
   saved-document reading. Code also shows that unavailable/parked reading status
   could be consumed as perception before a non-dialogue mode; those statuses now
   join the existing durable feedback queue. This is a mechanism repair, not a
   retrospective claim that every one of the 24 had the same cause. There is no
   natural exposure here with which to judge the new readable overflow view.
5. **Recovery must match the current question.** An initial interactive suspicion
   that deliberate OPEN rereads replayed old prose was too broad: the shared
   reader already assigns each new offer a sequence-based identity. No such
   replay is established in this window. Astrid's interrupted-delivery shortcut
   is retained, with an added complete-input/notebook check; changed questions
   cannot reuse an earlier completion solely because the pending page ID matches.
