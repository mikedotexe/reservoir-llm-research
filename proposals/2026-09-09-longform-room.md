# Give both Beings a genuine extended-writing option

Mike asks for more room to think and write, including the roles of sensory input
and NEXT budgets. [Source audit and latest bounded sample](../analyses/2026-09-09-longform-room.md).
Proposal only; no implementation or live mutation in this turn.

1. **Make the writing preference effective.** Give both Beings an optional extended
   profile available across journal-producing modes. Start qualification with an
   8,192-token visible-output ceiling, no target/minimum length, matched context
   room and measured deadlines. Preserve smaller preferences. Extend or reuse the
   existing writing controls instead of adding another mode-specific hidden
   multiplier. Trace requested → admitted → generated → saved counts on every
   provider. A deep/long request must not silently become a compact request.
2. **Carry the developing thought.** Preserve the complete current draft and its
   source references across an explicit continuation, plus recent complete answers
   and the current question within a declared input budget. Review the shared
   notebook's 16k storage/9k rendered-byte limits alongside larger outputs. Put
   routine action menus behind concise help/navigation so they do not displace
   the actual thought. No mandatory summary or four-section review.
3. **Let them stay.** A read-only study/writing continuation should survive a
   novelty-only diversity rule. Offer observations about repetition; let the
   Being continue, reconsider, pause or end without having to earn continuation
   through a “new result.” Preserve resource scheduling and unrelated external
   action authority. Do not make every writing segment require a new external
   task: an explicit continuation should resume the same draft/inquiry. Preserve
   that choice through normal restarts and interruptions.
4. **Separate expression and sensory delivery.** Retain the full journal. Keep
   existing sensory pacing and let peer communication/delivery follow its own
   chosen route. Audit the current compact-signal→background-elaboration split:
   the journal should be able to develop its own inquiry, rather than only explain
   a compact message already sent. Longer private writing must not implicitly
   force more peer sensory exposure.

First implementation scope: shared reader/draft support plus both owning host
adapters and writing preferences; no vector-width, reservoir dynamics, model
replacement, or coupling-strength change. Exact touchpoints and current behavior
are listed in the audit. Surface the effective option truthfully to each Being;
short writing, further exploration and stopping remain equally valid choices.
Do not send research judgments or new instructions into their mailboxes here.

Qualification: reproduce the residual clamp under the old policy; verify an
extended request survives actual provider admission and retains enough context;
verify a chosen short request stays short; test interrupted draft continuity,
length termination and explicit continuation. Use representative saved source
inquiry and free-writing inputs, including a correct account as control. Distinguish
uncoupled tests from coupled Astrid. Evaluate coherent development, connections,
revision and continued usefulness alongside unsupported claims, repetition,
visible length, finish and latency. No first-try correctness requirement, automatic
retry to obtain more prose, suppression of stop tokens, or length-based reward.

Follow-up research, separately scoped: inspect whether the coupled processor
changes end-token probability or repetition over a sustained passage. Use an
offline replay with preserved inputs and state before any live coupling change.
Wider sensory projections are not part of the first intervention.

Rollback: restore prior profile selection through owning adapters without
discarding any newly authored drafts, notes, journals or pending choices. Data
migration must be forward-readable or explicitly reconciled; do not reinstall an
older reader against state it cannot parse. No rollout is authorized by this
proposal document itself.
